# QI-01: Exact quotient identification from bounded partial observations

**2026-11-04, synthetic finite research note.** This is an interface-relative decision problem adjacent to [IRC-02](interface_relative_compactification.md), [MP-02](metaprune_set_cover.md), and the [QO-07 anytime active quotient](https://github.com/MoralityLabAI/Compactification-Theory/blob/main/research/ingression_dynamics_v1/ANYTIME_ACTIVE_QUOTIENT.md). Exact finite theorems and oracles are separated from statistical and real-model claims.

## 1. Declarative experiment interface

Let the microscopic transient state set be S={0,1}, let A be a finite action alphabet, and add a separately observable absorbing goal. The physical response table W is a **known-to-the-evaluator but unknown-to-the-agent** binary hit/hold matrix W_(i,a) in {0,1}, giving the deterministic probability of a goal hit when action a is applied to resettable named state i. Goal and state identities are fixed and visible. A query (i,a) reveals one cell value. The controller can adapt its next query to all past outcomes, has an integer budget, and must decide the Boolean proposition:

    Q_k(W): Does an EXACT goal-preserving one-step quotient exist with
            at most k transient macrostate classes?

Because the goal is separate and the transition law is hit/hold, Q_k(W) holds exactly when the set of distinct row vectors of W has size at most k. Distinct rows cannot share a zero-error macrostate because some action would assign different hit probabilities, while identical rows can be grouped. Thus the question is a finite exact-prediction capacity property.

An adaptive controller receives a declared finite **candidate world family** H rather than all possible matrices. Its worst-case cost is the maximum number of queries before outputting the correct Q_k(W) for every W in H. There are no sampling noises in Sections 1–3.

## 2. QI-01/T1: the zero-error two-state capacity lower bound

Fix d available actions. Let W_0 be the all-zero 2×d table. For each of its 2d cells c=(i,a), introduce an alternative W_c that agrees everywhere with W_0 except that cell c is changed from 0 to 1.

Then Q_1(W_0) is true, and Q_1(W_c) is false for every alternative. Every zero-error adaptive experiment policy deciding Q_1 on

    H = {W_0} union {W_c : c in S×A}

has **worst-case query complexity exactly 2d**.

**Proof.** Follow any correct decision tree on the baseline W_0. All answers on that path are 0. If some cell c were never queried along that path, W_c would give the same outcome on every selected query and therefore reach the identical terminal decision, incorrectly receiving the baseline label. Hence all 2d cells must be inspected on the baseline path, giving a lower bound 2d. Query each cell once and return the baseline label iff every response is zero; this is an exact protocol with worst-case 2d probes. QED.

The bit-cost consequence is that the baseline needs one transient macrostate plus the goal (one label bit), while each alternative needs two transients plus the goal (two bits). The lower bound concerns **evidence queries required to determine the correct capacity**, not the bit capacity itself.

## 3. QI-01/T2: exact SET COVER reduction

Let alternative worlds W_j be generated by flipping a nonempty subset C_j⊆A of the **first** transient state's action bits, leaving the second row all zero; the baseline is all-zero. Querying first-state action a returns 1 in alternative j exactly if a∈C_j. Queries to the second state always return 0 and add no discriminating information.

Let D* be the minimum worst-case number of adaptive queries required to decide Q_1 across the baseline and all these alternatives. The [MP-02 set-cover theorem](metaprune_set_cover.md) yields

\[
 \boxed{D^*=\min\{|T|:T\subseteq A,\ \forall j,\ T\cap C_j\ne\varnothing\}.}
\tag{1}
\]

*Proof.* On the baseline all queried values are zero. To distinguish every alternative W_j from that baseline, the baseline path's chosen action set must intersect each C_j. This is the hitting-set form of minimum set cover. Conversely, querying such a hitting set and stopping at the first positive result decides the property correctly with worst-case that many queries. QED.

The decision problem is NP-complete when the list of alternative supports is supplied explicitly and the bound on worst-case probes is part of the input, by the usual SET COVER/hitting-set reduction. This NP-completeness applies to the **candidate-world hypothesis discrimination contract**, not directly to finding the best partition of one fully known kernel table (QO-03/QO-04 study that separate problem).

## 4. Noisy exact equality cannot be decided with a finite zero-error budget

Now allow unknown Bernoulli probabilities in (0,1) under separately addressed resets. Consider two true worlds:

    A: p_(0,a)=1/2 and p_(1,a)=1/2.
    B: p_(0,a)=1/2 and p_(1,a)=5/8.

At tolerance zero with one transient macrostate, Q_1(A) holds and Q_1(B) fails. Yet every possible fixed finite sequence of addressed probe/observation pairs has **strictly positive probability in both worlds**. The same support overlap holds for finite adaptive decision trees: by induction on its chosen next cell, every binary outcome remains possible in either world.

**QI-01/T3.** Any finite-budget strategy with a deterministic, zero-error conclusion for both these Bernoulli worlds is impossible, even when named-state reset is available.

*Proof.* The two worlds assign positive probability to every possible binary response at every selected cell. Take a terminal observation history that occurs under A. It has positive probability under B and leads to the same decision by the policy's causality. If the decision is correct under A it is wrong under B. Randomization cannot give a zero-error classification across both worlds because each fixed random seed inherits the same overlapping support argument. QED.

The distinction is between **exact equality identification at finite data budget** and high-confidence error-tolerance certificates. QO-07's three-valued anytime certificate can remain unresolved until the evidence separates the worlds at the declared **positive** tolerance; no finite uniform zero-error assertion is warranted from noisy Bernoulli data without additional gap assumptions.
