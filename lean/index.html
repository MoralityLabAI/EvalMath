The lattice note (paper/evaluation_feedback_lattice.md, version 0.6)

Every theorem below is listed in axioms_lattice.lean. #print axioms gives [propext, Classical.choice, Quot.sound] for 49 of them and [propext, Quot.sound] for prop7_context_pair. The files contain no sorry, no new axioms and no compiled-code evaluation. Concrete values come from decide (multisets, finite sets) and norm_num (rationals).

Programme model (FeedbackChannel.PatchDP). A state is a multiset of pairs (n, F) with F ≤ n (Valid). A patch picks a category with n ≥ 1. It hits with probability F/n, leaving (n-1, F-1), and otherwise leaves (n-1, F). val H s is the Bellman minimum of the expected patches to H hits, computed with fuel equal to the items left (dp, val_succ). It differs from the Python _optimal_value in two ways, and neither changes a value on a feasible state: (i) categories with F = 0 stay in the state and may be patched, a wasted patch, which the note's policy class allows; (ii) an infeasible state (more hits needed than failures left) has the junk value 0, and every theorem assumes feasibility. val_le_pval shows that no legal stationary policy (a function of hits needed and state) does better than val. Randomised and history-dependent policies are not modelled. The values agree with the Python programme on every witness state.

Notes on the sources found while formalizing

  • selection-KL D.5: the telescoped form a_n(2)² = (1/16) ∏_{j<n} (2j+1)²/((2j)(2j+2)) has a zero denominator at j = 0; the product must run over 1 ≤ j < n (from a_1(2)² = 1/16).
  • multigen §6 (0.5): "(L1) holds for every law" is a theorem, not only a finite check. Under gains ≥ 0 and H non-decreasing in the level, the fixed-gain induction carries over unchanged (full_window_nonneg).
  • multigen Prop. 1 (ii) states the increment as E[(X - M_m)^+]; the formalization uses the equivalent tail form ∑_j F(j)^m (1 - F(j)).
  • multigen Prop. 5: the maximal-inequality step needs no λ > 0 once it is written as λ(E max - c) ≤ ln m + ln E e^{λ(X - c)}. Positivity is needed only to divide by λ.
