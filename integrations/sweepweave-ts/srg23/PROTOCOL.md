# SRG-23: Constrained authoring with frozen residual predictors

Public exploratory protocol committed before the authoring run. Preserve SRG-AC01/02 and original storyworld. Source b3ea7c7b197cd27708f987454cdd65fa9e915c95. Work only on generated SRG-18 cargo worlds, not Reservoir Dogs or production editor.

Train fixed ridge predictors on the original SRG-22 reaction cohort (all 16 original tapes, d1 nominal regret), lambda=1, intercept and standardized training features. Freeze both local and directed arms. Training uses source regret; authoring never uses candidate d1/d2/d4/terminal/independent-policy outcomes. Two fresh public cohorts, seed 0x53522301 and 0x53522302, four tapes each, H=4,6,8; W=4,8; C=1,2; B=6,12; first two terminal targets 0,1. No retuning after either cohort. Evaluate generated worlds with same public rules.

Candidates: unmodified source plus 16 seeded proposals per world. Each proposal performs two swaps of collect-reward entries within the same stage, preserving every stage's reward multiset, all phase maps, energy guards, action order, terminal goal/payoff, narrative templates and state support. Choose stage and distinct indices via fixed xorshift32 tape (rep, H,W,C,proposal; independent of target/bonus). Remove duplicates, never change original source. Candidate hard guards: absolute optimal utility change <=1 point, informative reachable decision fraction >=max(0.85, source fraction-0.03), number of stage identity cuts changing root Q >= max(H-1, source count-1). Exact DP only for these feasibility guards, not candidate control regret. Validate unchanged scope and reward histograms. Record all infeasible/duplicate candidates; baseline can fail a guard. No selective dropping based on observed policy regret.

Within each feasible pool with >=3 distinct worlds, freeze low, median and high by predicted d1 regret (tie by proposal index). Directed objective, local-only ablation and a deterministic hash-ranked random control use the exact same pool. Require directed predicted high-low gap >=0.03 to mark a base eligible for all arm comparisons; report coverage of all bases and all nonselected outcomes separately if needed, never silently omit. Freeze complete selection manifest before calculating candidate policy regret. Primary score: mean realized d1 nominal regret high-low and fraction of strictly positive matched high-low pairs. Gate for each cohort: eligibility >=60% of bases, mean high-low >=0.025, strict positive fraction >=60%, and directed exceeds local-only mean high-low by >=0.005. Require independent policy (uniform-suffix expected-return greedy: at each state choose immediate reward plus expected future reward under uniform legal actions, fixed menu ties) mean high-low >=0.01; report d2,d4,terminal-only separation as diagnostics. All comparisons use same denominator 3H+B and matched world groups, report low/mid/high means, ordering failures, exact attainable utility and informative/causal guard margins. No tuning on validation; publish failure if any gate fails. Independent policy is deterministic and public, not a trained model.

Compile selected directed tiers for at least one eligible base per H/W/C/B cell per cohort and replay all reachable projected state transitions (hidden score retained as one witness prefix). Check legal menus, public mode/energy/target, rewards and terminal. Verify training predictions fixed, candidate scope, source oracle consistency and scorer compatibility. Record cost as candidates/feature calls and exact guard DP counts; no speedup claim. Public synthetic calibration only, no actual model calls, independent private seeds or production authoring. A pass warrants further testing, not an automatic difficulty label in existing worlds.
