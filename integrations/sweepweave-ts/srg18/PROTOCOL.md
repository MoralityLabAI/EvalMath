# SRG-18: Coupled causal reaction chains (public protocol)

This protocol is fixed before running the new benchmark. It is a public exploratory calibration, not a sealed model evaluation. Preserve SRG-01–17B.

State is (turn, mode, energy). For each turn and mode, collect earns 1–3 points and follows a published permutation without spending energy; switch follows another permutation and spends one energy; recharge follows a third permutation and adds one energy. Switch and recharge have public energy guards. No inert padding: every turn has its own reaction maps and reward vector. At the end, earn a terminal bonus if mode equals the public target and energy is positive. The terminal reward is paid on the last reaction. Goal is total points. Full transition tables are public, so this is a deterministic planning gym.

Factorial grid: H=2,4,6,8; mode width W=2,4,8; energy cap C=1,2; terminal bonus B=6,12; 16 matched tapes (seed 0x53521801); evaluate every target mode for each tape/cell. Fixed action-order shuffle per stage. Identical tapes across target and bonus conditions. Initial mode is tape-derived, initial energy 1. Score full cohort and separately report strict terminal-target reversal pairs, chosen exhaustively within each matched base (both strict margins >=1 point, differing optimal root actions). No pair selection on model output.

Oracle: integer backward DP over (turn,mode,energy). Independently enumerate the complete action tree at H<=4 for every root, and at all H for one representative tape per cell. Controls: first legal; receding-horizon exact d=1,2,4; terminal-only full-depth planner (ignore running collect reward, with fixed ties); full oracle. Truncated search includes terminal reward only if the final turn falls within the search window; this describes a specified baseline rather than a lower bound on all algorithms. Report root accuracy, informative row accuracy, composed realized utility, paired regret, denominator and opportunity coverage per H and W. Enumerate only reachable rows. Report exact root lookahead threshold and whether all shallower depths disagree (do not assume monotonicity). For every stage j, clamp its phase map to identity for all actions, retaining energy and reward; report changes in root value, action-value vector, and strict optimal-action reversal. These are counterfactual sensitivity probes, not proofs that H is minimum computational depth. SWMD-SRG/2 replay uses actual guarded reactions and public phase/energy, with hidden cumulative score and explicit public rules. Compile at least one fixture per factor cell and check all reachable one-step transitions and terminal rewards. Run malformed/missing scorer checks. If any gate fails, report it without promotion.

No paid compute or actual model inference. Public seeds, 16 matched tapes, no independent statistical claims. A private independently frozen tape is required for model evaluation.
