# SRG-19: Stochastic reaction chains and belief-space planning

Public exploratory protocol, registered before the run. Preserve SRG-01–18.

Hidden binary mode z, public turn and one probe credit. Each stage has public desired mode b and work payoffs r0,r1 in {1,2,3}; work0 earns r0 iff z=b, work1 earns r1 iff z=1-b. Rewards are hidden until terminal. Work0 and probe apply the same stage-specific XOR permutation, work1 its complement. Each reaction independently flips the resulting mode with probability f/4. After each nonterminal action, a binary signal matches the new hidden mode with probability q/4, or certainty after probe. Probe earns zero, consumes its single credit, and is legal only while credit remains. The final reaction also earns B iff new mode matches the target. Final probe is legal but produces no useful signal. All rules are public; initial mode is drawn from a public tape-specific prior in {1/4,1/2,3/4}. No latent reward or mode leaks into observations.

Grid H=2,4,5; f=0,1 (quarters); q=2,3,4 (quarters); B=4,8; 8 matched public tapes (seed 0x53521901); both terminal targets for each base. Common stage parameters and prior across factors. Enumerate reachable posterior/credit states, not impossible histories. Model-facing planning packets give exact posterior masses; a separate history inference task is future work. Stage one-tape pilot before a private evaluation.

Exact Bellman: use integer unnormalized belief masses, gcd reduction and a 16^d scale for d-step expected utility (transition and observation denominators four each). Independent unnormalized action/observation tree enumeration at H=2 for every root and H=4,5 for representative tape. Check mass conservation, posterior equivalence, oracle policy evaluation, observation monotonicity in q (Blackwell order), no-probe and sham-probe ablations. Sham probe keeps the same dynamics and credit expenditure but has the ordinary channel. Controls first legal, receding d1/d2/d4, MAP certainty (full solver initialized at MAP mode each decision), no-probe optimal, full oracle. Score exact expected composed policy utility, root/informative accuracy, optimality gap, expected probe use, root action reversals under observation and target interventions. Do not assume deeper truncated planning improves every root.

Belief geometry: Hellinger embedding (sqrt(p0),sqrt(p1)), chord distance, posterior expected variance reduction and Bayes information gain; compute root action-value slopes and action-boundary witnesses where two posterior masses with common dynamics yield distinct strict actions. Report action boundary and value-of-information metrics separately; no claim of minimal computational complexity. SWMD-SRG/2 deterministic hidden-tape replay for at least one fixture per factor cell, using pre-sampled independent reaction/observation words per stage and action, guarded mode transitions and explicit public signal, credit and turn. Compare to the stochastic simulator conditioned on the same tape; runtime replay does not validate an RNG inside the editor. Score malformed/missing submissions. No actual model inference or paid compute; public tapes are repeated across conditions and are not independent statistical replicates.
