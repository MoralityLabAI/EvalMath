# SRG-20: Multivariate evidence and nested delegation

Public exploratory protocol, registered before execution. Preserve SRG-01–19.

A uniform hidden K-bit vector x determines a shared binary target by XOR parity of a public target mask. Agents A0 through AD each receive four conditionally independent noisy parity observations of public masks. First two masks repeat, making contradictory evidence possible. Agents have separate private histories. Each agent commits to a route (8 points if correct, zero otherwise) or delegates to its next agent at a public fee; the last agent must choose a route. Delegation subtracts the fee and follows the successor's precommitted policy. Successors commit using only their own private evidence, without observing the predecessor's selection, earlier private history, or realized fee. This is a common-payoff chain of fixed Bayesian policies, not strategic signaling or equilibrium analysis.

Grid: K=2,4,6; effective mask support R in unique {2,K}; D=1,2,3 delegation links; fee=0,1,2; precision profile equal (all q=3/4) or late (A0/A1 q=3/4, A2/A3 q=1). Eight matched tapes, public seed 0x53522001. Target mask is all R active bits; extra K-R bits are independent padding. For each agent the first mask is nonzero tape-derived, second repeats it, third and fourth are tape-derived with third forced to target for agents >=2 and fourth forced to target for agents >=1 on a tape flag. Masks and flags shared across depth, fee and precision. Enumerate every possible A0 history. Use exact likelihood integers with denominator 4^4 and exact recursively scaled utility vectors conditional on x. Last agent optimizes direct routes; each earlier agent uses its posterior to optimize direct or delegate to its fixed successor. Exact root utility evaluates each chosen action against the true full successor policy, weighted by actual history probability. Ties accepted, fixed action ordering for policy commitments.

Controls: first action; direct-only; root truncated delegation models d=1,2,3 (assume last modeled agent cannot delegate); last-observation posterior with full successor model; independent bit-marginal approximation with full successor model; exact oracle. Separate posterior inference scoring uses TV, squared Hellinger and target probability error for history controls. Report weighted utility, raw and weighted informative accuracy, strict action reversals and regret; group by K,R,D,fee,precision. Pair same last observation with different earlier histories and distinct strict oracle actions. Match equal R=2 with extra hidden padding; check utility invariance. Match D, fee, precision across tapes, evaluate zero-fee and free direct-only lower bounds. Record effective GF(2) mask rank (root and union), entropy perplexity, number of distinct posterior classes and empirical posterior feature covariance participation ratio if feasible. Nominal K, rank and nesting length are separate; no claim of minimum computational complexity. Independent explicit history tree check on representative small cases, all policy recurrence consistency checks, malformed/missing scorer checks. Separate model-facing history and posterior-supplied policy inputs for matched ablation; no actual model inference. SWMD-SRG/2 hidden-tape replay if feasible, with only active agent evidence projected, no previous actor private coordinates; document whether runtime enforces agent-specific views. Public repeated tapes, no independent statistical inference or paid compute.
