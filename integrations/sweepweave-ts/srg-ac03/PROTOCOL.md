# SRG-AC03: Legal upstream acquisition and route-access policy search

Public exploratory registration before execution. Freeze SRG-13 source (b3ea7c7b197cd27708f987454cdd65fa9e915c95) unchanged. This is a legal player-policy optimization, not a storyworld patch or production promotion. Goal is secret truce, horizon 3 from first sirens. Reuse matched absolute-index 24-word xorshift32 tapes, not semantic suffix actions when paths diverge. Branch over all legal actions at the first visit of four registered upstream sites: opening (options 0..3), timeline (0..2), radio (0..2), review (0..2). Outside those sites and on revisits use the coupled random index policy. Enumerate each tape's restricted decision tree with actual runtime transitions; a per-tape maximum is a clairvoyant upper envelope, not a deployable policy.

Finite public policy grammar: opening and timeline each either default random-index or fixed option; radio default/fixed 0,1,2 or inspect (2) only if no positive timeline record / only if a positive timeline record, otherwise option 1; review default/fixed 0,1,2 or request timeline review (2) only if exactly one prior positive record / fewer than two prior positive records, otherwise option 0. At unavailable forced option use baseline random index and count fallback. Total 5*4*6*6=720 policies, including baseline and fixed all-investigate with default opening (default,0,2,2). Adaptive rules use only public ledger and menu; no hidden coordinates or future words. First-visit state is public memory. No new reaction effects, gates, prose or routes.

Development cohorts n=32 each, seeds 0x53522301/02. Fresh validation n=96 each, seeds 0x53522311/12. Evaluate every policy on each matched development tape, using cached exact branch trees. Compute full-state H1/H3, informative root count, two-record activation, unique truce, actual random suffix terminal goal, and exact empirical H3 observation-history oracle for menu+ledger and goal4+ledger channels as in AC02. Report paired H3 gains/losses, energy share, route-access and realized source provenance. Verify each record increase against the selected reaction's original MAX(old, literal) write; check caps and monotonicity. Record every unavailable action, invalid path, missing target. Every complete legal prefix is allowed; the energy concentration is a review diagnostic, not a semantic rejection threshold for existing legal choices. Compare all policies to baseline on paired tapes.

Hard development guards per cohort: all campaigns reach sirens, all branches used valid, no unavailable overrides, both observation-oracle numerators and informative-root count nondecreasing, two-record activation nondecreasing, H3 paired losses <= floor(n/16). The paired loss budget (6.25%) is a chosen policy tradeoff, not author approval; also report how many policies pass stricter zero-loss gate. Rank passing policies by minimum goal4 gain then summed goal4 gain, minimum ledger gain, summed informative root gain, summed two-record activation, then fewest nondefault rules, then lexical enumeration. Require positive goal4 gain in both cohorts, otherwise freeze baseline. Freeze before evaluating fresh seeds. On validation require same guards and positive goal4 gains both cohorts; compare frozen, baseline and all-investigate, and transfer a fitted suffix policy from the pooled development roots to fresh validation using goal4 lookup, ledger fallback, first-legal fallback. This is actual composed lookup rollout on each reached root; oracle fitted separately on validation is a ceiling. No validation retuning. No actual language model, private evaluation, paid compute or production editor changes. Record finite sample results as descriptive, with 32/96 matched tape units per cohort.
