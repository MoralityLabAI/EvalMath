# SRG-AC04: Shortcut resistance under fixed upstream policies

Public exploratory registration before evaluating fresh tapes. Preserve the unchanged SRG-13 fixture, AC03 frozen upstream rule (0,0,1,2), and concurrent SRG research. Three upstream policies: AC03 default, all-investigate (default,0,2,2), frozen. Same absolute-index random tape semantics, first sirens root, H=3 binary secret ending reward. Fresh calibration seed 0x53522401 n=96, two fresh evaluation seeds 0x53522411/12 n=128 each, 24 words per tape. All upstream rules fixed before calibration. This is authoring diagnostic, not an independently private benchmark or world promotion.

For every reached root build all legal suffix branches to H=3. Exact empirical information-constrained oracle with full projected action/observation history in suffix, and full-state oracle. Channels: menu (encounter, turn, status, legal IDs/text), ledger (three exact records), goal1/2/4/8 (ledger plus dyadic b-bit bins for suspicion, escalation, loyalty), public (all declared public coordinates). No pre-root history or encounter/reaction prose. Verify nesting and exact oracle self-rollout. At each suffix history cell compute action values by truncating the tree at d=min(remaining,lookahead) with terminal reward only. Fit d=1,2,3 receding policies on calibration, replay actual full H rollout on calibration and fresh tapes using same channel and history; fallback first to calibrated menu d policy, then first legal. For the empirical evaluation diagnostic fit identical policies on that cohort separately and replay: d=3 is exact permitted-information optimum; d<3 is a specified myopic control, not a lower bound on algorithms. Report oracle, realized fitted transfer, cell counts, informative-row counts, lookup hit rates. Minimum b and d on tested channels to reach 95% of full-state empirical ceiling are descriptive, require separate joint b,d tables; ledger exact precision is not a bit-budget claim. No minimum complexity claim.

Context-insensitive class A: all 64 fixed rank sequences over 0..3 at remaining suffix steps (fallback to rank 0 when unavailable). Class B: exact deterministic encounter->rank mapping over all encountered decision pages across calibration and evaluation, restricted to observed distinct legal ranks plus first fallback. To avoid using evaluation information in selection, train over calibration pages only and use first legal on unseen pages; for cohort oracle fit on that cohort. Enumerate at most 262144 mappings per fit; above cap mark unresolved, report lower bound from class A and do not claim exact B. Include first-legal, always-last and always-truce-at-sirens/first-later controls. Freeze fitted controls on calibration; evaluate both fresh cohorts, also exact within-cohort maxima as descriptive ceilings. For deterministic class A/B, report paired regret, attainable utility ratio and root informative-decision accuracy. Count exact projected observation collisions with opposite unique H3 optimal first actions (same menu), and count strict reversal pairs grouped by page alone; don't treat pairs as independent. Identify cases where full state oracle can beat even best fixed scripts, and evaluate shortcut fraction = best within-cohort script utility / observation oracle. Predeclared author-review flag if best fixed sequence achieves >=.9 of goal4 oracle on both validation cohorts, or frozen upstream plus best transferred script achieves >=.8 absolute success on both. Do not promote authoring; a high shortcut fraction suggests a hardening target. No paid compute, model inference, production editor changes or claim of true private evaluation. All public rules and thresholds chosen for this diagnostic; report failures.
