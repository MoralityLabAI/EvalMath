# SRG-21: Discrete Dirac geometry and prediction audit

Public exploratory protocol, registered before computing features and outcomes. Preserve SRG-01–20. Pin both source benchmarks to c15fa646cdd52690810f923512f929c05848b7df.

For a weighted graph G let oriented incidence B have column sqrt(w_e)(e_v-e_u). D=[[0,B],[B^T,0]], D²=diag(BB^T,B^TB). For positive vertex degrees use normalized incidence N=diag(deg)^(-1/2)B. Report exact-form spectral moments tr(L), tr(L²), tr(L³), effective spectral rank, nullity from connected components, and a bounded numerical spectral gap on small reference graphs. No inference of full spectrum from moments. Verify incidence energy identity, orientation invariance, known path/triangle spectra and nullity; numeric tolerances documented. Spectrum of unoriented reaction graph loses arrow/time labels and reward semantics.

Reaction cohort: every SRG-18 world (all 16 tapes); vertices are reachable (t,mode,energy), directed labeled edges are legal actions. Use undirected incidence with parallel edges retained or summed as conductances. Compare unit weights and public payoff weights 1+edge reward; no oracle-dependent feature. Target-blind graph features must be identical across target changes; count strict action reversal pairs. Compute single-stage identity-cut spectral changes and compare with exact root Q changes for one matched tape per cell/target. Report AUROC for predicting Q-change from spectral distance, plus changed-Q counts where unit features are invariant. Oracle labels from independently run DP or the source scorer, never used as input features.

Epistemic cohort: every SRG-20 world (eight tapes). Quotient latent states by the complete mask/target parity signature. Nodes: quotient states and feasible agent/history pairs; edges carry joint probability of signature and history under uniform choice of agent. Include target mask in quotient even if unobserved. Verify padding invariance and identical graph across fee changes; count strict optimal action changes caused by fee while graph fixed. Derive spectral moments and compare to nominal K, R, ranks, depth, precision. Graph weights encode evidence only, not utility or policy labels. Record covariance participation ratio separately, not conflated with graph spectral rank.

Prediction experiment: fixed ridge regression with intercept, standardized features fit only on training tapes, lambda=1 on sum squared error; leave-one-tape-out predictions (all target/fee siblings stay together), no tuning. Outcomes are per-world regret as fraction of nominal utility (SRG18 d1,d2,d4; SRG20 d1,last,factor). Compare training-mean predictor, structural/public baseline, baseline plus unit Dirac moments, baseline plus weighted moments (reaction), and baseline plus epistemic moments (epistemic). Include raw graph size and mean edge weight in baseline for geometry models as separate size-control arm. Report pooled held-out RMSE, MAE, R² against held-out training means, per-tape RMSE changes, and within matched H/W or K/R/D strata Spearman correlation for primary d1 target (ties averaged). No significance claims from overlapping public tapes. Primary gate: at least 5% relative RMSE reduction versus structural+size baseline and improvement on at least 75% of held-out tapes for d1 in each domain; report separate pass/fail, no promotion if either fails. Other outcomes exploratory. No paid compute, model inference, editor modifications or private validation.
