# SRG-25: Reasoner-population geometry and held-out response prediction

Public exploratory protocol, registered before data analysis. Preserve SRG-24 and concurrent authoring work. Source pinned to ef74263d59830712a83dee5a7f76f1f1f0b4fec9. Use every feasible unique SRG-24 candidate (including unselected and ineligible bases), joined by cohort, base ID and proposal index to the frozen guard/selection and post-freeze audit receipts. Six distinct policy columns: d1,d2,terminal,uniform,beam,d4; exclude derived min columns and oracle constant. Regret is source nominal utility fraction. Weight each base equally, variants within base uniformly. Keep target and bonus siblings and all variants on the same (cohort,tape) split. Report counts and joins. Do not infer generality from selected tiers alone.

Geometry: weighted column-centered 6x6 covariance; symmetric Jacobi eigensolver, singular values of sqrt(weight) times centered matrix; variance explained, spectral participation ratio, rank-one residual. Separately double-center each row (remove row mean then column mean) for relative-profile geometry. Verify trace, orthogonality, reconstruction, PSD within 1e-9, and invariance under column permutation. Report loadings with deterministic signs (largest magnitude entry positive), pairwise weighted Pearson correlations, matched-base strict ordering reversals per reasoner pair, and exact scalar anchor mean collisions with >=.05 held-out-regret difference. Use training-only d1/d2/terminal anchor profiles; describe clusters using k=3 deterministic farthest-first k-means on row-centered six-policy profiles, fit on cohort 1 and assign cohort 2, weighted by base. Cluster descriptions use all outcomes and are descriptive, not predictive.

Prediction: observe only anchor d1,d2,terminal on test worlds; target uniform,beam,d4 labels available only on calibration worlds. This is held-out-world response prediction for calibrated target policies, not cold-start prediction of a never-measured reasoner. Fixed weighted ridge (intercept, training-only standardization, lambda=1 on sum weighted squared error; rescale training weights to mean 1). Compare structural baseline H,W,C,B,initial target indicator omitted because not in receipt, guard optimum/(3H+B), informative fraction, sensitive-stage fraction, proposal swap count; structural+scalar anchor mean; structural+top 1/2/3 PCA scores of weighted centered raw anchor covariance; structural+raw three anchors. Fixed primary arm PCA2 vs scalar. Leave-one-(cohort,tape)-out across all 8 folds; report weighted RMSE/MAE/R2 vs training means per target, macro-average RMSE, improvement count per held-out tape, per-cohort metrics. Also freeze fit on all SRG-24 feasible candidates and transfer without refitting to two fresh public unedited SRG-18 cohorts (0x53522501,0x53522502, eight tapes each, H=6,8; W=4,8; C=1,2; B=6,12; targets 0,1). Compute new source control rollouts and uniform-suffix and width-2 beam policies exactly as SRG-24; guard features by exact DP and stage cuts; proposal swap count zero. Fresh transfer is distribution-shift diagnostic, not private evaluation. No tuning.

Primary promotion gate: PCA2 macro RMSE at least 5% below scalar and improvement on >=6/8 held-out tapes; no target RMSE worsens >2%. Require >=5% macro improvement on each fresh transfer cohort and no target worsens >2% on either. Compare PCA1/PCA3/raw as diagnostics, no post-hoc substitution. Report failure honestly. Stratify regret and geometry by feasible pool and original (proposal 0 where feasible), not a claim of minimum reasoning depth. No actual model inference, private test, new editor changes or paid compute. CLI verification with pinned source/receipts; report if standalone Node not run.
