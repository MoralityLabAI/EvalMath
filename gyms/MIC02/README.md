## Four finite problems

* Recurrence: for strictly upper-triangular integer M with row sums <=8, certify 10p >= 10b+Mp. A scalar upper certificate is feasible. Reverse topological tightening gives the least integer certificate by induction. This is a finite integer restriction of MIC-01, and has a specialized exact solver.
* Amortized analysis: on a directed cost graph choose potentials phi in {-2,0,2}, with vertex 0 anchored to zero. B=max(0,max_e[c_e+phi(v)-phi(u)]) certifies total path cost <= kB+phi(start)-phi(end), by telescoping. Exhaustive oracle is restricted to the declared potential grid. Coordinate descent accepts a strict decrease and can stall.
* Counting: for unknown nonnegative counts x, constraints Ax<=b imply sum x <= (p dot b)/4 whenever p>=0 and A^T p>=4. Restrict weights p to integers 0..4. Coordinate tightening preserves feasibility. This is a fractional-cover upper certificate, not a claim of tight primal or continuous dual optimum.
* Derandomization: partial Boolean assignments yield 32 times the expected count of unsatisfied clauses, calculated exactly. Assigning a variable to the better child cannot increase expectation, since the parent is the arithmetic mean of its children. Endpoint is a complete assignment; enumeration gives the optimal endpoint. This is a finite conditional-expectation task, not an asymptotic derandomization theorem.

Each arm gets five coordinate updates, each coordinate once, and the same charged initial candidate scan; this is a matched operation-count proxy, without measured runtime matching. Static order ranks immediate gain at the initial certificate; reverse order and three seeded permutations serve as controls. None of the controls uses oracle labels in scheduling. Compare normalized final objective (lower is better), dividing by max(1, initial objective). The primary comparison is ordered versus first shuffled; the remaining two shuffled arms form the matched sham. Full enumeration over all 120 permutations is a retrospective diagnostic, not a second confirmation experiment.
